# 🎓 CS-Student: USTHB L1 Study Space

An offline-first, feature-rich Android application designed specifically for First-Year Computer Science students at **USTHB** (Université des Sciences et de la Technologie Houari Boumediene). 

Built using modern Android development best practices and the latest Jetpack libraries, CS-Student serves as a centralized hub for course materials, announcements, announcements, and academic resources.

---

##  Key Features

-  **Secure Google Authentication**: Firebase Auth integration allowing students to sign in securely.
-  **Module Explorer**: Browse core L1 CS subjects (Algorithms, Mathematical Programming, Structures, Analysis, Algebra, ICT).
-  **Resource Sharing & Filtering**: Access documents (PDFs), video tutorials, and useful links organized by module and semester.
-  **Multi-Language Localization**: Full support for **English** and **French** with an instant in-app language switcher.
-  **Push Notifications**: Integrated Firebase Cloud Messaging (FCM) support to receive real-time updates and announcements.
-  **Admin Management**: Dedicated role-based admin panel to post news/resources and manage content with confirmation dialogs.
-  **Offline-First Architecture**: Powered by Room Database for seamless offline viewing and synchronization.

---

##  Tech Stack & Architecture

- **UI Framework**: [Jetpack Compose](https://developer.android.com/jetpack/compose) & Material 3
- **Architecture**: MVVM (Model-View-ViewModel) with Kotlin Coroutines & Flow
- **Dependency Injection**: [Hilt (Dagger)](https://dagger.dev/hilt/)
- **Local Database**: [Room Database](https://developer.android.com/training/data-storage/room) (KSP)
- **Backend & Auth**: [Firebase Firestore](https://firebase.google.com/docs/firestore) & [Firebase Authentication](https://firebase.google.com/docs/auth)
- **Cloud Messaging**: [Firebase Cloud Messaging (FCM)](https://firebase.google.com/docs/cloud-messaging)
- **Image Loading**: [Coil](https://coil-kt.github.io/coil/)
- **Navigation**: [Jetpack Navigation Compose](https://developer.android.com/guide/navigation/navigation-getting-started)
